## 🌟 Overview

**ApexForge** is a high-performance, single-file web application built for serious exam aspirants preparing for competitive exams like **GATE CS 2027**. 

Designed with modern glassmorphism aesthetics, dynamic micro-animations, and gamified progress tracking, **ApexForge** runs entirely in your browser using `localStorage`. No logins, no cloud tracking, no fluff — just raw focus, discipline, and measurable results.

---

## ✨ Key Features

### 🔥 75 Days Hard Exam Challenge
An intense 75-day discipline module built specifically for exam readiness:
- **5 Daily Hard Rules**: 4+ Study Hours, 20+ Practice PYQs, 1 Core Concept Revision, 1 Distraction-Free Focus Session, and a Daily Reflection Journal Note.
- **Visual 75-Day Grid Map**: Dynamic status indicators (`✓ Done`, `🔥 Active`, `🔒 Locked`).
- **Milestone Badges**: Unlock badges at Day 7 (Week 1 Survivor), Day 15 (Bronze Discipline), Day 30 (Iron Scholar), Day 50 (Mastery Mode), and Day 75 (Legendary Graduate).
- **Dashboard Status Widget**: Compact real-time streak and progress card right on the main dashboard.

---

### ✅ Today's To-Do List Widget
Stay accountable every day with a clean, interactive task manager directly on your dashboard:
- Fast task creation with instant enter-key support.
- Click-to-complete checkboxes with smooth strikethrough animations.
- Dynamic completion progress bar (`X of Y tasks completed`).
- LocalStorage persistence across browser restarts.

---

### ⏱️ Pomodoro Engine & Audio Oasis
Boost study focus with an integrated Pomodoro system:
- Customizable focus, short break, and long break timers.
- **Audio Oasis**: Ambient soundscapes (Lofi Beats, Soft Rain, Deep Forest) to enhance concentration.
- Automatic session logging feeding directly into daily study analytics.

---

### 💻 GATE CS 2027 & PYQ Tracker
Structured syllabus management for GATE Computer Science:
- **Complete Unit & Topic Progress**: Track subtopic completion across Engineering Math, Digital Logic, COA, DSA, Algorithms, TOC, Compiler, OS, DBMS, and Computer Networks.
- **PYQ Tracker**: Year-wise PYQ solver with difficulty tagging (Easy, Medium, Hard) and real-time accuracy analytics.

---

### 📝 Study Notes Hub & Formula Flashcard Deck
- **Subject-Wise Notes**: Markdown-enabled quick note-taking attached to specific exam units.
- **Spaced Repetition Flashcards**: SRS-driven formula deck with SM-2 algorithm scheduling (`Again`, `Hard`, `Good`, `Easy`).

---

### 📈 Analytics & Completion Forecast
- **Daily & Weekly Charts**: Bar charts analyzing study hours per day and subject distribution.
- **Completion Velocity Forecast**: AI-calculated pace estimator projecting your exact exam syllabus finish date.

## 🚀 Quick Start

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Abhinav201310/ApexForge.git
   ```
2. Open `index.html` directly in any web browser (Chrome, Edge, Firefox).
3. (Optional) Run via local HTTP server:
   ```bash
   npx http-server -p 8080
   ```
4. Access the web app at **`http://localhost:8080`**.
